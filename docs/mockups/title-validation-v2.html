Design notes

  • Both — Status picker + "Add to Library" button anchored at the bottom above navbar, within thumb zone. Info at top (read), actions at bottom (interact).
  • Proposal A — Full-width hero cover (like Title Detail), title over gradient. Source badge overlaid on hero. Feels immersive, like you're already looking at the title page. Reuses the Title Detail hero pattern.
  • Proposal B — Side-by-side cover + info (like the original v1). Source badge in the header bar. More compact, shows all info at a glance without scrolling. Cover is larger than v1 (120×180).
  • The "already in library" and "match fix" states would use the same bottom-anchored layout — the action area just changes (View button / Confirm button instead of status picker).
