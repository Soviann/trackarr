Design notes

  • Both — Search input anchored at the bottom, just above navbar. Auto-focuses on tab tap.
  • Proposal A — Shows results state: compact rows with cover, title, status badge, metadata. Results grow upward from the input.
  • Proposal B — Shows empty state before typing: centered icon + hint text. Teal border on input = focused state with cursor hint.
  • These are two states of the same screen, not alternatives. Both are needed.
