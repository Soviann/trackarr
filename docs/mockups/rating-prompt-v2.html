Design notes

  • Both — Full bottom sheet with dimmed backdrop. Title as amber link to detail page. Three-tier actions: "Save rating" primary, IMDb/AniList side by side, "Skip for now" as text.
  • Proposal A — 5×2 number grid. Large tap targets, zero ambiguity. One tap to select. Sheet is taller but every element is easy to hit.
  • Proposal B — Slider with big number display. More tactile/fun interaction. Compact vertically. Snaps to integers. Might be fiddly on small screens.
  • AniList "Save & sync" — Only shown for anime titles with confirmed AniList match.
