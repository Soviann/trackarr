Design notes

  • Shared screen — same component for Add (paste/search), Share Target (Android share sheet), and Match Review (fix match). Only the header, source badge, and action area change.
  • Source badge — subtle pill showing where the URL came from (IMDb, AniList, TVDB, or "Search").
  • External IDs — tappable chips in brand colors. Same style as match-review-list.
  • State 1 (new) — status picker + amber "Add to Library" CTA.
  • State 2 (exists) — amber info card showing current status/progress + "View in Library" outline button.
  • State 3 (fix match) — shows Plex source → resolved match with confidence box. "Enter IDs manually" expandable. Green "Confirm Match" CTA.
  • State 4 (loading) — skeleton placeholders + spinner while the matching pipeline resolves.
