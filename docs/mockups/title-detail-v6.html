Design notes

  • Both — Edit button on hero (top-right pencil). Action bar with S__E__ format. Rate button shows current rating when rated (amber star + score).
  • Proposal A — Unwatched episodes listed first, watched collapsed into "7 watched episodes" toggle. Less scrolling, focus on what's next. Edit button only (no AniList badge — this is a non-anime title).
  • Proposal B — All episodes chronological (same as v5). AniList badge shown (anime title) with amber dot = pending match. Full episode list gives complete overview.
  • AniList badge — Only visible on anime titles. Amber dot = pending match, red dot = not connected, no dot = confirmed.
