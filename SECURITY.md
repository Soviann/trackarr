# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest major release.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The security of Trackarr and the safety of our users' private media tracking instances are top priorities.

If you discover a security vulnerability, please **DO NOT** open a public issue on GitHub.

Instead, please report it securely through GitHub:
- Submit a confidential report via [**GitHub Private Vulnerability Reporting**](https://github.com/Soviann/trackarr/security/advisories/new).

### What to include in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions (or a minimal Proof of Concept) to reproduce the issue.
- Details about your environment (Docker version, reverse proxy setup, OS, browser).

### What to expect:
- **Acknowledgement**: We will acknowledge your report within 48 hours.
- **Assessment**: We will investigate and validate the issue promptly.
- **Fix & Disclosure**: We will prepare a patch, test it, and release a patched version with appropriate security advisories and credit to the reporter.

Thank you for helping keep Trackarr safe!
